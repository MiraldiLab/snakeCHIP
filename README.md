# snakeCHIP
A snakemake workflow for ChIP-seq processing. Unlike the main branch, the "quantChip" branch also generates quantitative ChIP-seq signal tracks (linear fold change, counts per million), used to train quantitative maxATAC (quant-maxATAC) models (Rizvi et al., 2025). Distinguishing features of the quantChIP branch are indicated in purple (see Figure below).
